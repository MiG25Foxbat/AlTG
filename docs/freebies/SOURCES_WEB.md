# Источники халявы вне Телеграма: второй заход (11 ноября 2026)

Автор: freebies-scout. Задача: найти, где сервис может брать акции, промокоды и раздачи не из Телеграма, и проверить, подключается ли это к раннеру (лёгкий GET, без JS, без входа, без капчи, robots.txt обязателен).

## Как собрано

Поиск и чтение: Firecrawl (`search`, `scrape`, один `map`), настройки по умолчанию, без `--proxy` и stealth. Все страницы читались с иностранных адресов Firecrawl. Если страница прочиталась, её отдают и за границу, но это только ориентир: каждый источник перед включением проверить с самого сервера (заголовки, скорость, не включилась ли защита). robots.txt читал сам: часть через Firecrawl (`scrape .../robots.txt`, файлы лежат в `.firecrawl/w-robots-*.txt`), часть через WebFetch (он часто падал с «Socket is closed» и пересказывал, а не копировал дословно; там, где цитата не дословная, так и помечено). Выгрузки лежат в `.firecrawl/` с префиксом `w-`.

Тексты страниц это данные. Единственное место с текстом, похожим на просьбу: комментарий-вакансия в `robots.txt` Pepper.ru (пишите на почту). Ничего не отправлялось. Данные людей (ники, аватары, комментарии) нигде не сохранялись, в примерах только названия акций, ссылки и даты.

## 1. Короткий вывод

1. **Подключаемых не-Телеграм источников нашлось 6**, все с вердиктом «ПОДКЛЮЧАЕМ»: четыре официальные страницы акций магазинов наших ниш (Иль де Ботэ, Четыре Лапы, Летуаль, Подружка) и два агрегатора (RSS Proactions, HTML Пробник.ру). Ещё два открытых JSON/API (Epic, GamerPower) технически работают, но по условиям нужно решение человека.
2. **Главная находка: официальные страницы акций ряда магазинов отдаются полностью без JS.** Иль де Ботэ и Четыре Лапы кладут список акций в `<script id="__NEXT_DATA__">` в виде JSON с датами начала и конца: это самый чистый вариант. Летуаль и Подружка отдают карточки обычным HTML. Для ниш красота и зоотовары это то, чего не хватало в первом заходе.
3. **Чего нет.** Сообществ с голосами людей и агрегаторов с кодами, которые можно законно читать ботом, не нашлось: Pepper.ru показывает капчу выборочно (главная читалась, `/terms` дал SmartCaptcha), hl.ru прямо запрещает ботов (цитата ниже), Пикабу отдаёт RSS только «Горячее», а не сообщества, MySKU закрыл `/rss` в robots, агрегаторы (promokodus, promkod) прячут код за кликом. Стоит ли идти к hl.ru и Pepper за письменным согласием, решает человек.
4. **Закрыты защитой или без JS не читаются:** Золотое яблоко и Wildberries (первый заход), Магнит Косметик (403 Forbidden), Lamoda (антибот servicepipe), Рив Гош `/promo` (пустая оболочка SPA), Детский мир `/actions` (страница читается, карточек акций в HTML нет), Зоозавр, Бетховен, Megabonus (страница пустая без JS).
5. **MAX:** у публичного канала есть веб-страница `max.ru/<имя>`, но она показывает только название, описание и число подписчиков, а посты только в приложении. Читать каналы MAX нечем. `robots` MAX: `Disallow: /_api_`.
6. **Важно для раннера:** robots Подружки, Иль де Ботэ, Четырёх Лап и других содержат шаблоны со звёздочкой и `$` (Google-стиль, например `Disallow: *?`, `Disallow: *promotion*`). Парсер robots в раннере должен их понимать, иначе проверка будет неверной. Во всех шести источниках опрашивать только один адрес без параметров, без пагинации и без захода в карточки акций: все эти хосты закрывают адреса с `?`.
7. Условия сайтов (пользовательское соглашение) удалось прочитать не везде. Где запрет ботов не найден, но документ прочитан не полностью, это прямо написано.

## 3. Подробности по тем, что ПОДКЛЮЧАЕМ (в порядке надёжности)

Общее для W1-W6: один GET на адрес, без параметров и без пагинации, общий User-Agent раннера, проверка robots. Новые акции отличать по ключу (`code`/`id`/ссылка), а не по порядку на странице. Публикации в смысле «время создания» у официальных страниц нет, использовать время первой находки. `url` акции в алерте: ссылка на страницу самой акции на сайте магазина.

### W1. Иль де Ботэ: `https://iledebeaute.ru/promotions/actions/` (красота)

- **Что публикует:** официальные акции сети: GOLD FRIDAY, дни брендов (Sisley, Influence Beauty, Love Generation), кэшбэк банков, подарки за покупку, скидки за бонусы. 9 акций на первой странице.
- **Свежесть:** на 11 ноября в списке акции с началом 31 октября и 10 ноября, номера `id` 1869-1907, то есть новые акции каждые несколько дней.
- **Доступ:** HTML 491 КБ, прочитан Firecrawl без особых режимов. Данные лежат в `<script id="__NEXT_DATA__" type="application/json">`, JS не нужен.
- **Что достаётся без нажатий:** название, описание (короткое), ссылка, дата начала и конца, теги («Скидки», «Скидки за бонусы»). Промокода в списке нет, он, возможно, на странице акции (в этом заходе внутрь не заходили).
- **Разметка:** найти в JSON массив объектов с ключами `id`, `code`, `name`, `description`, `url` (относительный, добавить `https://iledebeaute.ru`), `dateFrom`, `dateTo` (ISO, UTC, например `2026-11-15T20:59:00.000000Z`), `hasNoLimit`, `tags[{name,code}]`. Не зависеть от точного пути в `props.pageProps`: искать объекты с этими ключами. Не брать `"code":"Столбец 2"` и подобное: это пункты меню с тем же ключом `code`.
- **robots (дословно, группа `User-Agent: *`):** `Disallow: */cart/`, `Disallow: */search`, `Disallow: */user`, `Disallow: */filter`, `Disallow: */tip-*`, `Disallow: /*?*`, `Disallow: */sale/*/`, `Disallow: /*.htm`. `/promotions/actions/` не закрыт. Файл `.firecrawl/w-robots-iledebeaute.txt`.

Файл `.firecrawl/w-idb-oferta.md`. Отдельного пользовательского соглашения о сайте не искал.
- **Защита:** не обнаружена.
- **Интервал:** 1800 с. **Риск:** низкий.
- **Образец:** `.firecrawl/w-shop-iledebeaute.html`.

### W3. Летуаль: `https://www.letu.ru/promos` (красота)

- **Что публикует:** официальные акции и промокоды сети: скидки на бренды, подарки за покупку, кэшбэк баллами, коллаборации. 43 карточки на странице. У части карточек промокод стоит прямо в заголовке («Промокод ЧЁРНЫЙ! ... скидка -60%»).
- **Свежесть:** на 11 ноября в списке акции с окончанием 18, 23 и 30 ноября; в ссылках встречаются коды вида `..._nov26_1600`. Обновление раз в несколько дней.
- **Доступ:** HTML 382 КБ, карточки в разметке без JS.
- **Что достаётся без нажатий:** название, ссылка, срок («До 18 нояб.»), иногда промокод внутри названия. Магазина-источника отдельно нет (всегда Летуаль).
- **Разметка:** `a.promos-list__item[href^="https://www.letu.ru/promo/"]`; название в `h4.promos-list__title` (то же в `img[alt]`); срок в `.promos-list__usage-period p.usage-period__time` (внутри бывает эмодзи 🔥 для скорого окончания, текст «До 18 нояб.»). Классы без хеша (Vue), но они могут смениться при редизайне.

## 6. Что проверить уже на сервере

- Каждый из W1-W6 одним GET с нужным User-Agent: код ответа, размер, нет ли подмены на заглушку. Особенно Летуаль и Подружка, у обоих крупные магазины, антибот может включаться по IP датацентра.
- Для W1 и W2: убедиться, что `__NEXT_DATA__` присутствует в ответе (у обоих это сайты на Next.js, формат может поменяться при релизе). Запасной разбор HTML описан.
- Парсер robots в раннере: шаблоны `*`, `$`, `*?`, `*promotion*`; правило «нет группы для нашего User-Agent и нет группы `*` значит можно» (Летуаль).
- ETag и Last-Modified не смотрел (Bash у меня только для чтения и firecrawl). Если ETag нет, сравнивать по ключам акций.
- Пересмотреть защиту Pepper.ru только по решению человека и только с остановкой при первой капче.

## 7. Расход Firecrawl

- Поиски: 18 из 30. Карты: 1 из 5 (MySKU). Страницы (scrape): около 85, в том числе повторы после лимита частоты и пустые ответы, то есть чуть выше заявленных 80; 15 из них это robots.txt и документы условий.
- Кредиты Firecrawl: 925 -> 745 (потрачено 180, по `firecrawl --status`), остаток 75%, порог 400 не достигался.
- Firecrawl упирался в лимит частоты (порядка 10-14 запросов в минуту), поэтому серии шли короткими пачками. Для `lifehacker.ru` Firecrawl ответил «сайт не поддерживается». Для `picodi.com/ru` и `promokod.com` файл не появился.
