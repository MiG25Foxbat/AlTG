Причина: в этой сборке Claude Code нет инструмента создания команды (TeamCreate), у Agent параметр `team_name` помечен устаревшим и игнорируется («у сессии одна неявная команда»). Помощники запущены как именованные фоновые агенты этой неявной команды, адресуются по имени через SendMessage, лид для них `main`. Другие папки в `~/.claude/teams/` (session-26133ba8 и др.) от других сессий, в них только team-lead.
- Решил сам: не останавливаться. Третий повтор ничего не изменит, параметр игнорируется. Суть проверки (четыре помощника с нужными именами, которым можно писать) подтверждена через ListAgents. Остановка оставила бы человеку пустую ветку.

Решил сам: лид работает узлом связи, просьба «для <имя>: ...» в отчёте передаётся лидом; помощник после отчёта останавливается и запускается снова сообщением лида. Записано в начале CONTRACT.md.

## Решения
- Решил сам: `src/modules/BotModule/bot.ts` отдан freebies-ui (только подключение `/freebies` и кнопок `fr:`), чтобы быстрые настройки бота делал один владелец от начала до конца. Остальные файлы бота не правятся.
- Решил сам: в общей ленте «Каналы» это уже сохранённые в базе посты отслеживаемых каналов за сутки (`loadUnifiedPosts`), без запроса в Telegram при открытии ленты.
- Решил сам: «пробивать тихие часы» снимает только тихие часы, пауза из бота действует всегда. Существующая `holdUntil()` переиспользуется без правки: `loud: false`, `quietEnabled = quietEnabled && !breakQuiet`.
- Решил сам: у халявы свои тихие часы и дневной лимит в `freebies_settings`, по умолчанию как у тем (23:00–08:00 МСК), лимит 30 в день.
- Решил сам: придержанная акция при выпуске пропускается, если срок вышел или срока нет и прошло больше 6 часов. Акции живут минуты, утром слать ночное бессмысленно.
- Решил сам: `npm run dev` и `npm start` команде запрещены, они подключаются к настоящему Telegram и боту (риск `AUTH_KEY_DUPLICATED`). Для просмотра freebies-backend делает `src/freebiesDemo.ts` на in-memory базе без Telegram.
