## Решения
- Решил сам: `src/modules/BotModule/bot.ts` отдан freebies-ui (только подключение `/freebies` и кнопок `fr:`), чтобы быстрые настройки бота делал один владелец от начала до конца. Принят и вынос общего ответа на нажатие в `sendOutcome()`: тело перенесено без изменений, иначе была бы копия девяти строк.
- Решил сам: в общей ленте «Каналы» это уже сохранённые в базе посты отслеживаемых каналов за сутки (`loadUnifiedPosts`), без запроса в Telegram при открытии ленты.
- Решил сам: «пробивать тихие часы» снимает только тихие часы, пауза из бота действует всегда. Существующая `holdUntil()` переиспользуется без правки: `loud: false`, `quietEnabled = quietEnabled && !breakQuiet`.
- Решил сам: у халявы свои тихие часы и дневной лимит в `freebies_settings`, по умолчанию как у тем (23:00–08:00 МСК), лимит 30 в день.
- Решил сам (по замечанию reviewer): придержанная акция при выпуске пропускается, если срок вышел или срока нет и от публикации прошло больше часа. Ночью халява не копится, интерфейс это подписывает.
- Решил сам: всё найденное при первой успешной проверке источника сохраняется без рассылки (`muted`), иначе вся лента источника разошлась бы разом.
- Решил сам: `npm run dev` и `npm start` команде запрещены, они подключаются к настоящему Telegram и боту (риск `AUTH_KEY_DUPLICATED`). Для просмотра freebies-backend делает `src/freebiesDemo.ts` на in-memory базе без Telegram.
- Решил сам: три источника первого захода это веб-превью публичных Telegram-каналов `t.me/s/<канал>` по HTTP через раннер: S1 `promokodi_skidki_beauty` (промокоды ЗЯ и WB, 120 с), S2 `Promokodi_zolotoe_yabloko` (ЗЯ, 120 с), S4 `wildberriesru_official` (официальный WB, 300 с). Пикабу не взят: код спрятан за кнопкой, обновление раз в день, условия про парсинг не найдены.
- Решил сам: kind `telegram` (через общий MTProto-аккаунт) в первом заходе не реализуется, источников под него нет. В контракте описан на будущее.
- Решил сам: `url` акции из каналов это ссылка на сам пост `https://t.me/<канал>/<id>`, а не партнёрская ссылка автора канала из текста.
- Решил сам: у акции в ленте `at` = время публикации, чтобы порядок совпадал с «N мин назад».
- Решил сам: оператору hl.ru за согласием не пишем, это отправка сообщения людям. Решение за человеком.

## Принятые риски
- Условия Telegram для веб-превью `t.me/s` не проверены. Риск принят: один запрос к t.me за раз, не чаще раза в 120 секунд на канал, общий User-Agent без личных данных, robots.txt t.me отдаёт 404. Доступность t.me/s с зарубежного сервера проверить с самого сервера.
