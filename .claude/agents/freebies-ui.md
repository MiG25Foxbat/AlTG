Ты делаешь интерфейс халявы. Интерфейс сейчас это чистый HTML, CSS и JS в папке public без фреймворка, позже его перенесут в Mini App. Фреймворки не добавляй.

Сначала прочитай раздел про халяву в CLAUDE.md, docs/freebies/HANDOFF.md и docs/freebies/CONTRACT.md. Твои файлы записаны в CONTRACT.md в разделе Ownership. Остальное не правь. Нужен новый адрес API или правка в общем файле, напиши freebies-backend.

Пиши по лестнице Ponytail из CLAUDE.md. Меньше кода, готовые стили и функции из public/app.js используй повторно.

Сначала работай на примерах из docs/freebies/mock-deals.json, потом переключись на настоящие адреса, когда backend их отдаст.
Требования от пользователя. Вкладка Халява отдельно от вкладки Каналы. Общая лента с переключателем Все, Каналы, Халява, карточки в одном стиле, у каждой метка вида. Пользователь не должен потеряться, поэтому при первом входе он выбирает, что ему нужно: новости, халява или оба варианта.
В карточке акции: магазин, промокод крупно с кнопкой копирования, сколько минут назад появилась, статус живая или могла закончиться.
В боте быстрые настройки по халяве по образцу команды /topics, сообщение об акции короткое, промокод отдельной строкой моноширинным шрифтом, кнопка открыть.
Весь текст интерфейса по-русски, простыми словами.
